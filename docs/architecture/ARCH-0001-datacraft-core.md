# ARCH-0001 - DataCraft Core v0.0.1

## Objet
Définir le squelette model-centric du Core DataCraft.

## Chaîne canonique
`PROJECT -> PROFILE -> CAPABILITY -> SKILL -> POLICY -> RESOLVER -> CON/ADP/ENG -> SYS`

## Identité
- Handle: identité interne immuable.
- ID: identifiant humain canonique.
- Alias: conservation permanente des anciens IDs.
- Path: emplacement mutable, jamais identité primaire.

## Frontières
Les moteurs et logiciels externes sont intégrés par adapters et restent remplaçables. Une source de vérité unique est définie par responsabilité.
